# Дмитрий Тимофеев — Portfolio

Персональное портфолио Дмитрия Тимофеева.

## Структура проекта

- `index.html` — главная страница
- `style.css` — стили
- `assets/` — изображения и галерея
- `videos/` — видео
- `models/` — 3D-модели
- `wb-covers/` — обложки для Wildberries
- `mirex-mandarin/` — материалы кейса MiRex / Мандарин

## Локальный запуск

Открыть `index.html` в браузере.

Для корректной работы 3D-моделей и медиа рекомендуется запускать через локальный HTTP-сервер.

## Контент

Портфолио содержит проекты, 3D-модели, видео, графику и материалы кейсов.
